# ICLR 与正式 CVIU 评测的协议对照

当前正式模型结果尚未完整，以下只比较协议与冻结输入，不比较模型性能。

| 项目 | ICLR 稿内实验 | 当前正式评测 | 解释边界 |
|---|---|---|---|
| 核心 grounding 输入 | 四个修复来源对构建两视图拼接板；查询和左右位置置换，每干预 16 个配对查询 | 30 场景、每场景 8 目标、每目标 2 视角，480 对单幅场景图 | 扩大跨场景覆盖，但未复现拼接板的查询/位置交换设计 |
| 读出诊断 | 30 对 raster archive，像素/0–1000 坐标与 JSON/两行文本交叉 | 固定 0–1000 坐标，单行 Point: x, y | 新实验控制读出，不构成格式消融 |
| 评分 | 目标区域/框命中，完整查询分母；包含输出覆盖分析 | 条件各自可见实例掩码为主，框命中、有效输出率、固定点/均匀像素基线为辅 | 掩码严格程度不同，不能将命中率差解释为能力提升 |
| 模型 | 六种模型配置；拼接板、读出与采样子实验覆盖不同 | Qwen3-VL-8B 与 32B，固定 revision、BF16、无量化/卸载 | 同系列容量对照，不代表所有模型，也非参数量的因果隔离 |
| 重复运行 | raster 子实验有三次随机解码；导航缺同条件重复 | 三个独立进程的贪心解码复跑；另有三场景完整重复渲染 | 贪心复跑不等于随机解码不确定性估计 |
| 不确定性 | 目标簇 bootstrap | 场景簇 bootstrap，保留场景内目标/视角/复跑，10000 次，固定 seed | 不能把 5760 条预测当作 5760 个独立场景 |
| 导航 | 三个场景、99 对 episode，52→48 成功，17 损失/13 增益 | 当前 goal 没有新导航复跑 | 不能用新 grounding 数据消除旧导航随机性疑问 |
| 干预解释 | 完整材质转换及目标窗口交叉实验 | 完整材质转换；固定掩码复评分诊断 | 不隔离颜色、纹理、显著性、背景或单个材质参数 |

当前任务采用原始条件资格筛选，转换后的语义线索丢失仍保留。历史 pilot 使用两条件可见性资格筛选，不能与正式数据合并。单图多视角设计也不能声称解决了 ICLR 拼接板所检查的所有查询依赖问题。

## 冻结输入的中心基线

- original: 掩码中心命中 131/480；框中心命中 213/480；空掩码 0；均匀像素期望命中率 0.115127。
- converted: 掩码中心命中 132/480；框中心命中 213/480；空掩码 0；均匀像素期望命中率 0.115303。

这些是输入基线，不是模型结果。旧稿明确指出 close-view pool 的 30 个目标框全部覆盖图像中心，而两图拼接任务的中心为中间空隙；当前单图任务须同时报告自身中心基线，不能沿用旧拼接任务“中心零命中”的结论。

## 历史证据限制

旧 corrected analysis 的部分 run inventory 已标记 changed_images（完整列表及源文件哈希见同目录 JSON）。这些历史结果应保留其来源与警示，不能把当前文件重新读取后的分数当成历史运行复现。旧导航定量结果和轨迹展示来自不同运行，稿内也明确区分。

当前正式结果完整后，补充两模型主指标、逐例得失、同条件复跑、重复渲染对照和容量差异的区间；任何比较必须保留上述任务、总体、评分和解码差异。
